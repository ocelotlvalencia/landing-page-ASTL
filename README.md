# ASTL Technology Consulting

Landing page para ASTL Technology Consulting, desarrollada con Astro, Tailwind CSS y GSAP.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Desarrollo local

```bash
npm run dev
```

La página se sirve normalmente en:

```bash
http://127.0.0.1:4321
```

## Deploy

El proyecto genera salida estática con Astro y está preparado para desplegarse en Vercel.
